# SmartGrahak.in 🛒

A modern **MERN Stack E-commerce Web Application** designed to simplify online shopping and inventory management. SmartGrahak provides customers with a seamless shopping experience while giving administrators powerful tools to manage products, orders, and inventory efficiently.

---

## 🚀 Features

### 👤 User Features
- User Registration
- Login & Logout
- Secure JWT Authentication
- Google Sign-In
- Facebook Sign-In
- Browse Products
- Search Inventory
- Add Products to Cart
- Place Orders
- Responsive Design
- Protected Routes

### 🛠️ Admin Features
- Admin Dashboard
- Inventory Management
- Add Products
- Update Products
- Delete Products
- Search Inventory
- Manage Categories
- View Customer Orders

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- JWT (JSON Web Token)
- Google OAuth
- Facebook OAuth
- Bcrypt.js

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/smartgrahak.in.git
cd smartgrahak.in
```

### Install Backend Dependencies

```bash
cd api
npm install
```

### Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

---

## ▶️ Run the Project

### Start Backend

```bash
cd api
npm run dev
```

### Start Frontend

```bash
cd frontend
npm run dev
```
